## 定位与处理

- 修复前最新 HTML 为 1,866,469 字节，本地 gzip 为263,153字节。页面在 head 内同步加载 jsDelivr 的 ECharts，该脚本解压后1,034,102字节，且在页面样式和主要内容之前加载。
- 本次同一线路分别测量：GitHub报告 HTTP 200，首字节6.943526秒、总计7.119988秒、压缩传输278,689字节；外部图表脚本 HTTP 200，首字节7.285152秒、总计7.567401秒、压缩传输335,130字节。这是单次请求样本，不是用户设备的完整首屏计时或速度保证。等待响应占主要耗时，实际报告下载在首字节之后约0.18秒完成。
- 市场散点图改为页面内的原生 SVG，取消外部图表库请求。保持价格/溢价坐标、RV颜色、筛选联动、点击/键盘打开详情和随容器宽度缩放。未估值的债券在图例中明确归入中性灰。
- JSON 仅移除序列化空白，不删除字段、债券、历史日期或曲线。最新 HTML 为 1,715,730 字节，减少 8.1%；本地 gzip 为 259,256 字节。主要收益是去掉额外的阻塞脚本，而非仅压缩这几千字节的传输量。
