# 强赎普通定价与推荐修复验收 · 2026-10-11

修复强赎债券仍按原合同多年期限计算普通 BS 价格、被误判为低估或错误划入 Delta 分组的问题。本次在 72e01a3 修订基础上增加强赎事件排除，原本的历史映射与可成交退出修复仍保留。修复前代码、数据和报告保存在独立本地备份；不以提高收益作为验收条件。

## 生效规则

- 已有带来源的强赎决定公告，从公告发布日起停止普通 BS 估值、RV、Delta/Gamma/Theta/Vega 和所有常规推荐（含双低、低估与 Delta 分组）。只确认触发条件而未决定行使赎回权，不等同于强赎实施。
- 强赎决定与实施条款分开保存；按公开日期顺序应用事件，与事件表的存储顺序无关。实施公告发布前不假造最后交易日、转股结束日或赎回付款金额。已核验公告不会在发布前影响历史信号。
- 只有永久停交观察、尚无可核验赎回类型/完整条款的债券，显示“赎回/终止条款待核验”，保守退出普通估值和推荐；不把它们擅自认定为强赎或到期兑付。临时停牌保持独立，已核实的到期兑付也保持独立。
- 有真实当日行情、尚可交易的债券仍保留观察行。被排除行的六个普通模型字段同步从文件和数据库清空，网页明确显示原因；报告与回测共同调用同一事件闸门。隐含波动率仍直接读取 iFinD 指标，普通模型仍使用历史波动率。
- 公告前已有持仓仍需逐笔验证实际退出报价或真实付款；无证据的退出不能记成零收益，也不能沿用停交后的报价。

## 重建与验收

- 覆盖 2026-04-20 至 2026-10-09 的 115 个交易日，34,491 条报告观察；报价返回 34,491 条，缺失 0、空白价格 0、未恢复批次错误 0。预期名单、dataset、universe、CSV、数据库及 HTML 的代码集合完全一致；本次没有改变已接受的当日样本和真实行情。
- 393 条观察（36 只债券）被普通模型闸门排除，其中已核验强赎 30 条、条款待核验 363 条。六个模型字段在文件和数据库中均为空，网页的 RV 与 Delta 为空且明确标示排除原因；所有数据库策略名单均不包含被排除行。
- 42 个窗口重新计算并校验回测；73 个窗口因样本不足或无法核验退出省略曲线，并写明原因。全部日期先完成定价和推荐重建，再计算任何回测；每日报告严格校验通过后才渲染。
- 5,921 条已有独立成交证据只用于已有持仓的买入/退出校验，未加入当日推荐名单；本次离线重建没有请求 iFinD 接口。
- 191 项 pytest 全部通过，包含决定公告与实施条款先后时序、禁止公告前回填、文件/数据库清空、报告与回测共用闸门、强赎/到期/临时停牌区分，以及旧估值残留阻止发布的回归测试。
- 独立验收逐日再次运行严格发布校验，并核对 HTML 的完整 view model、真实报价日期/成交量、数据库模型字段和所有策略成员。

## 保留的限制

历史归档中部分静态停交字段没有原始查询/首次公告时间，仍只按旧归档的观察日期处理并保守排除。这不等同于证明当时市场已经知道未来停交日，可能过早排除部分历史标的；本次只对有可核验公开来源的事件增加精确公开日期。另有10个历史成员 JSON 来自原同日样本重建，部分公司资料使用缓存。因此当前回测仍不能声称为完整时点认证数据。
普通债券仍使用简化 BS，尚未完整建模下修、回售及赎回触发概率；强赎事件债本次停止普通定价，没有伪造所谓精确强赎期权价格。
iFinD data_pool 月度额度错误 -4318 是已有未解决的供应商额度限制。本次依赖完整已核验的本地日期快照，不代表新交易日抓取权限已恢复；新日期无完整快照时仍须抓取成功才可发布。
逐日原始报价审计留在本地 data/raw/asof=YYYY-MM-DD/quote_audit.json，名单为同目录 cbond_codes.txt；原始数据、数据库、访问凭据不加入 Git 提交。
